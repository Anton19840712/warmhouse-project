# Temperature API

Симулятор температурных датчиков для системы "Тёплый дом". Предоставляет HTTP API для получения случайных значений температуры (10-40°C) по локации или ID датчика. Используется Go монолитом для получения актуальных показаний. Поддерживает локации: Living Room (ID: 1), Bedroom (ID: 2), Kitchen (ID: 3). Запуск: `dotnet run` или через Docker. Swagger UI доступен на `/swagger`.
